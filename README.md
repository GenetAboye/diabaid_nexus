# DiabAid Nexus

DiabAid Nexus is a user-centered mobile health application developed to support
diabetes self-management in Sub-Saharan Africa.

The application was designed through a human-centered development process informed
by the needs of people living with diabetes and healthcare professionals.

## Main Features

- Blood glucose logging
- Insulin tracking
- Diabetes education
- Medication and self-management reminders
- Emergency information
- Patient-centered diabetes support
- Bilingual user interface

## Development

DiabAid Nexus was developed using:

- Flutter
- Dart

The project involved:

- user-needs assessment
- stakeholder engagement
- user-centered design
- mobile application development
- usability testing
- real-world evaluation

## Usability Evaluation

The application was evaluated in an eight-week usability study involving people
living with diabetes in Ethiopia.

The evaluation examined the usability and acceptability of the application in a
real-world setting.
