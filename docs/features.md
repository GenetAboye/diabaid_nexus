# Application Features

## Blood Glucose Logging

Users can record and review blood glucose measurements.

## Insulin Tracking

The application supports recording insulin use as part of diabetes self-management.

## Educational Resources

Diabetes-related educational information is included to support self-management.

## Reminders

The application includes reminder functionality to support regular self-management
activities.

## Emergency Information

Users can access information relevant to diabetes-related emergency situations.

## Bilingual Design

The application was designed to support users in the local context through a
bilingual interface.
